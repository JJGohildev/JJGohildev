## Selected projects

### [Customer Experience Analytics](https://github.com/JJGohildev/cx-analytics-dashboard)

Power BI analysis of support volume, customer satisfaction, response times, and first-contact resolution. The project includes SQL validation checks, a data model, and documented DAX measures. It uses simulated customer-support data for a fictional company.

**Tools:** Power BI, SQL, Excel, Power Query, DAX  
[Explore project](https://github.com/JJGohildev/cx-analytics-dashboard) · [Read case study](https://github.com/JJGohildev/cx-analytics-dashboard/blob/main/case_study.md)

### [HR Performance and Reporting Automation](https://github.com/JJGohildev/HR-Performance-KPI-dashboard)

Power BI reporting on headcount, attrition, engagement, and training using simulated workforce data. Alongside the report, an Excel VBA routine is designed to refresh workbook data and export a PDF summary. Power BI refresh is handled separately.

**Tools:** Power BI, SQL, Excel, Power Query, DAX, VBA  
[Explore project](https://github.com/JJGohildev/HR-Performance-KPI-dashboard) · [Read case study](https://github.com/JJGohildev/HR-Performance-KPI-dashboard/blob/main/case_study.md)

### [British Airways Reviews](https://github.com/JJGohildev/ba-reviews-tableau-dashboard)

Tableau analysis of 901 historical reviews, comparing service ratings, passenger groups, and monthly patterns. The analysis highlights missing data and differences in sample size, including just 14 Wi-Fi ratings, to put the comparisons in context.

**Tools:** Tableau, SQL, Excel  
[View interactive dashboard](https://public.tableau.com/app/profile/jaydipsinh.gohil/viz/BritishAirwaysReviewsDashboard_17889618499830/OverviewTrends) · [Explore project](https://github.com/JJGohildev/ba-reviews-tableau-dashboard) · [Read case study](https://github.com/JJGohildev/ba-reviews-tableau-dashboard/blob/main/case_study.md)
